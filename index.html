Questions fréquentes

Création d'expansion, import de samples, One Shot / Note On…

Comment créer une expansion MPC gratuitement ?

Ouvrez Expansion Lab, glissez vos samples sur les pads, ajoutez une image puis cliquez sur « Télécharger l'expansion ». Décompressez et copiez le dossier dans Expansions à la racine de votre carte SD ou clé USB.

Comment importer des samples sur ma MPC ?

Glissez vos WAV, MP3, AIFF ou FLAC sur les pads : l'application crée un programme drum .xpm avec les WAV, prêt à charger sur la MPC ou dans le logiciel MPC.

Comment mettre une image sur une expansion MPC ?

Déposez une image JPG ou PNG dans la zone « pochette ». Elle est recadrée en carré et enregistrée dans l'expansion : elle s'affiche dans Browser › Expansions.

Quelle différence entre One Shot et Note On ?

One Shot : le son est joué en entier, même si vous relâchez le pad (kicks, snares, claps). Note On : le son s'arrête quand vous relâchez le pad (808 longues, nappes, voix). Réglable pad par pad avec le bouton ⚙.

Est-ce compatible avec les pads MPCe de la MPC Live III ?

Oui. Cliquez sur MPCe en haut de l'appli : chaque pad peut avoir 4 sons (un par coin, ou mélangés selon la position XY) ou 1 son avec un effet piloté par X / Y. L'export contient une piste MPCe (.xtd) avec ses sons, en plus du kit classique pour toutes les MPC.

Est-ce disponible sur Windows ?

Oui : installez-la comme une application depuis Edge ou Chrome, ou téléchargez la version hors-ligne (.zip). Voir la section Télécharger pour Windows.

Est-ce vraiment gratuit ?

Oui : gratuit, open source (licence MIT), sans inscription ni publicité.
